# 📱 بستهٔ ۳۰۹ قلق تعمیر گوشی — بردخان

این بسته **۳۰۹ قلق تعمیر گوشی موبایل به زبان فارسی** به‌همراه **۳۰۹ عکس یکتا** (هر قلق عکس مخصوص خودش — سئو) و **۱۲۰ ویدیوی آموزشی آپارات** را به دیتابیس سایت اضافه می‌کند.

## ✨ محتوا

| بخش | تعداد | با ویدیو |
|---|---|---|
| آیفون | ۷۶ قلق | ۲۹ |
| سامسونگ | ۷۰ قلق | ۳۲ |
| شیائومی / ردمی / پوکو | ۵۴ قلق | ۲۳ |
| هواوی | ۲۶ قلق | ۱۰ |
| آنر | ۶ قلق | ۳ |
| عمومی (ابزار، برد، صدا، ریکاوری) | ۱۸ قلق | ۱۸ |
| سایر / آموزشی | ۵۹ قلق | ۵ |
| **جمع** | **۳۰۹ قلق** | **۱۲۰** |

هر قلق شامل: عنوان، خلاصه، توضیح کامل، ۴ گام راه‌حل گام‌به‌گام، ابزار لازم، برچسب‌ها، سطح سختی، **عکس یکتا** و در ۱۲۰ مورد **ویدیوی آموزشی آپارات** (embed قانونی) است.

توزیع دسترسی (طبق قاعدهٔ ثابت سید): رایگان ۲۰۶ / لایک‌دار ۷۷ / پولی ۲۶ — منتخب ۱۰۳.

## 🖼 عکس‌ها — هر قلق یک عکس یکتا (سئو)

- ۳۰۹ فایل `tip-001.jpg … tip-309.jpg` — هر کدام با برش، زوم، رنگ، الگو و آیکون متفاوت + عنوان فارسی قلق
- تخت در ریشهٔ `uploads/` (سازگار با `serve.php` که فقط ریشه را سرو می‌کند)
- منشأ: ۱۵ عکس پایهٔ آزاد (Pexels/Wikimedia/AI) + خط تولید تنوع بصری ۵ لایه‌ای

## 🚀 نصب / به‌روزرسانی — فقط یک آدرس (پیشنهادی)

فایل‌های بسته را کنار فایل‌های سایت بگذارید (`seed-all.php` در `public_html`، پوشه‌های `seed-data` و `uploads-seed` همان‌جا) و فقط این آدرس را باز کنید:

```text
https://bordkhan.ir/seed-all.php?key=INSTALL_KEY
```

این یک URL همه‌کاره است و خودش به‌ترتیب انجام می‌دهد:

1. **کپی رسانه‌ها** — همهٔ `tip-*.jpg` به ریشهٔ `uploads/` (مقصد از `UPLOAD_DIR` config خوانده می‌شود)
2. **اصلاح مسیر عکس‌های قدیمی** (fiximgs)
3. **مهاجرت عکس یکتا** — قلق‌های موجود که عکس مشترک دارند، به `tip-NNN.jpg` اختصاصی خودشان مهاجرت می‌کنند
4. **درج/به‌روزرسانی هر ۳۰۹ قلق** — قلق‌های قبلی آپدیت می‌شوند (عنوان تکراری دوباره درج نمی‌شود) و ۱۰۰ قلق جدید اضافه می‌شوند
5. ثبت وضعیت در `bk_seed_state` برای اجرای resume

پیش‌نمایش بدون نوشتن در دیتابیس:

```text
https://bordkhan.ir/seed-all.php?key=KEY&list=1
```

اگر وسط کار صفحه قطع شد، **دوباره همان آدرس را باز کنید** — از همان‌جا ادامه می‌دهد.

## 🌐 نصب قدیمی دو‌مرحله‌ای (جایگزین)

```text
https://bordkhan.ir/copy_seed_media.php?key=INSTALL_KEY
https://bordkhan.ir/seed_tips.php?key=INSTALL_KEY
```

گزینه‌های seed_tips: `&list=1` (پیش‌نمایش ۳۰۹ عنوان) و `&fresh=1` (حذف قلق‌های سید و نصب از نو).

## 🔧 phpMyAdmin (بدون اجرای PHP)

`seed-data/seed_mobile_tips.sql` را در phpMyAdmin → Import اجرا کنید (اجرای دوباره امن است). سپس `seed-all.php` را یک‌بار باز کنید تا عکس‌ها کپی و مسیرها یکتا شوند.

## ▶️ فیکس پخش ویدیو (مهم)

پوشهٔ `site-update/` داخل این بسته، دو فایل اصلاح‌شدهٔ سایت است:

- `index.php` — پخش‌کنندهٔ آپارات با `allow=autoplay; fullscreen` + لینک جایگزین «اگر پخش نشد»
- `assets/style.css` — رفع باگ `pointer-events:none` که جلوی کلیک روی دکمهٔ پلی را می‌گرفت

این دو فایل را جای فایل‌های فعلی در `public_html` بگذارید (بکاپ نسخهٔ قبلی را نگه دارید). بدون این آپلود، ویدیوها فقط پوستر دارند و پلی نمی‌شوند.

## ❓ رفع خطاهای رایج

| مشکل | راه‌حل |
|---|---|
| HTTP 500 | فایل باید در `public_html` کنار `config.php` باشد یا داخل `php-extended/` |
| «دسترسی مجاز نیست» | `?key=` را با `INSTALL_KEY` داخل `config.php` بگذارید |
| «کاربر نویسنده پیدا نشد» | اول `install.php` را اجرا کنید |
| تصاویر 404 | `seed-all.php` را باز کنید؛ مرحلهٔ کپی خودش انجام می‌شود |
| ویدیو پخش نمی‌شود | `index.php` و `assets/style.css` جدید را آپلود کنید (رفع باگ `pointer-events` روی iframe آپارات) |

## ⚠️ پس از نصب

1. فایل‌های `seed-all.php` و `seed_tips.php` و `copy_seed_media.php` را از سرور **حذف کنید**.
2. یک‌بار `/opcache_clear.php?key=INSTALL_KEY` را باز کنید تا کش PHP خالی شود.
3. در پنل ادمین باید **۳۰۹ قلق منتشرشده** ببینید؛ ویدیوی هر قلق در صفحهٔ خودش باید **پخش** شود.
