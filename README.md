# بردخان — نسخهٔ کامل PHP (هم‌ظاهر با React)

نسخهٔ کامل PHP + MySQL با تمام امکانات (پنل مدیریت کامل، فروشگاه برد، قلق‌ها، کیف پول،
تیکت، درگاه پرداخت، نوار شناور و …) و ظاهر دقیقاً مطابق نسخهٔ React (تم دارک/سبز، فونت وزیرمتن).

## نصب روی هاست cPanel (۵ گام)
1. همهٔ فایل‌های این ZIP را در public_html آپلود کنید (فایل‌های مخفی .htaccess و .user.ini هم منتقل شوند).
2. در cPanel یک دیتابیس MySQL و کاربر بسازید و به هم وصل کنید.
3. در مرورگر باز کنید: https://YOURDOMAIN/install.php و مراحل نصب را کامل کنید
   (یا config.php را دستی پر کرده و schema.sql را در phpMyAdmin ایمپورت کنید).
4. یک‌بار باز کنید: https://YOURDOMAIN/php-extended/migrate.php?key=INSTALL_KEY
   (برای ساخت جداول تیکت/درگاه/نوار شناور) — سپس این فایل را حذف کنید.
5. وارد /admin شوید (با حساب مدیری که در نصب ساختید) و تنظیمات مالی/درگاه را وارد کنید.

## امکانات
- طراحی دقیقاً مثل React (assets/style.css تم React را دارد)
- پنل مدیریت کامل: تأیید/رد قلق و برد، کاربران، تسویه، دسته‌بندی، تنظیمات، جمع‌آوری خودکار
- فروشگاه برد: ثبت/ویرایش/حذف برد (فروشنده و مدیر)، خرید با امانت وجه، کد رهگیری اجباری
- قلق‌ها: ثبت با تصویر و ویدیو، لایک، امتیاز، علاقه‌مندی، قفل محتوا (رایگان/با لایک/پرداختی)
- کیف پول با درگاه (زرین‌پال/آیدیپی/زیبال) + کارت‌به‌کارت، تیکت پشتیبانی، اشتراک ویژه، معرفی دوستان
- نوار شناور پایین صفحه (قابل ویرایش از /admin-actionbar)

## نکات
- پوشهٔ uploads باید قابل نوشتن باشد (chmod 755).
- پس از نصب، install.php و php-extended/migrate.php را حذف یا محدود کنید.
