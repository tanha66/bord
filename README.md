# بردخان — نسخه PHP (هاست اشتراکی cPanel)

نسخه کامل PHP + MySQL بدون نیاز به Node.js، npm، Next.js یا PostgreSQL.
طراحی‌شده برای اجرا روی Apache + mod_rewrite در cPanel.

## 🚀 نصب (فقط ۳ مرحله — بدون ویرایش هیچ فایلی)

### مرحله ۱: ساخت دیتابیس در cPanel
1. وارد cPanel شوید → بخش **MySQL Databases**
2. یک دیتابیس بسازید (مثلاً `user_bordkhan`)
3. یک کاربر بسازید (مثلاً `user_bordkhan_user`) و رمز بدهید
4. کاربر را به دیتابیس وصل کنید و تیک **ALL PRIVILEGES** را بزنید

### مرحله ۲: آپلود
1. محتوای پوشه را داخل `public_html` آپلود کنید
2. در File Manager گزینه **Extract** را بزنید (تا فایل‌های مخفی `.htaccess` و `.user.ini` هم منتقل شوند)

### مرحله ۳: نصب
1. در مرورگر باز کنید: `https://bordkhan.ir/install.php`
2. **نام دیتابیس، کاربر، رمز و Host** را وارد کنید → «ادامه و تست اتصال»
3. **نام سایت، آدرس سایت، نام مدیر، شماره موبایل و رمز مدیر** را وارد کنید → «نصب نهایی»

تمام! نصب‌کننده خودش فایل `config.php` را می‌سازد، جداول را ایجاد می‌کند و مدیر را ثبت می‌کند.

> ⚠️ بعد از نصب، فایل `install.php` را حذف یا تغییرنام دهید و رمز مدیر را از پنل تغییر دهید.

### ورود به مدیریت
```text
آدرس: https://bordkhan.ir/login
شماره موبایل: (همان که در نصب وارد کردید)
رمز عبور: (همان که در نصب وارد کردید)
```

## امکانات نسخه PHP

- صفحه اصلی + دسته‌بندی‌ها + جستجو و فیلتر پیشرفته + جستجوی زنده
- ثبت‌نام / ورود / تأیید پیامکی نمایشی
- آپلود قلق با چند عکس + تشخیص خودکار محتوای تکراری
- قلق رایگان / با لایک / پرداختی + قفل محتوا
- محافظت تصویر و ویدیو (واترمارک، nonce، غیرفعال‌کردن راست‌کلیک و ذخیره)
- کیف پول + تراکنش‌ها + درخواست تسویه (شبا/کارت/کدملی)
- درخواست تعمیر + پاسخ تعمیرکاران + انتخاب بهترین پاسخ
- نظرات + امتیازدهی + علاقه‌مندی + نشانک
- پروفایل + دنبال‌کردن + رتبه‌بندی + نشان‌ها
- اشتراک ویژه (۱/۳/۱۲ ماهه) + معرفی دوستان
- صفحه ریلز تمام‌صفحه (اسکرول اینستاگرامی قلق‌ها + لایک — بدون هدر/فوتر)
- صفحه آموزش و امکانات سایت
- پنل مدیریت کامل (داشبورد، کاربران، قلق‌ها، گزارش‌ها، دسته‌بندی‌ها، تسویه‌ها، تراکنش‌ها، تنظیمات سایت/سئو، جمع‌آوری خودکار)
- جمع‌آوری خودکار قلق: جستجوی خودکار در شبکه‌های اجتماعی (ردیت) و نتایج وب، تبدیل به فارسی روان و انتشار به‌عنوان محتوای بومی + اجرای زمان‌بندی‌شده با Cron
- سئو: متاتگ، OpenGraph، Google Analytics، robots.txt و sitemap.xml

## نیازمندی هاست

- PHP 8.1 یا بالاتر
- MySQL 5.7+ / MariaDB 10.4+
- PDO MySQL + mbstring + fileinfo + json + GD (اختیاری برای واترمارک)
- Apache با mod_rewrite
- upload_max_filesize حداقل 10M و post_max_size حداقل 12M

در cPanel از بخش **Select PHP Version** این اکستنشن‌ها را فعال کنید:
`pdo_mysql`, `mbstring`, `fileinfo`, `json`, `gd`

## زمان‌بندی جمع‌آوری خودکار (Cron)

در cPanel → Cron Jobs، هر بازه دلخواه (مثلاً هر ۶ ساعت) دستور زیر را اجرا کنید:

```
wget -q -O /dev/null "https://example.com/cron-collect?key=CLAVE"
```

کلید را از پنل مدیریت → جمع‌آوری خودکار بردارید.

## نکات مهم

- کد تأیید پیامکی و پرداخت آنلاین فعلاً به‌صورت نمایشی هستند و باید به سرویس واقعی (کاوه‌نگار/ملی‌پیامک و زرین‌پال/آیدی‌پی) متصل شوند.
- جمع‌آوری خودکار فقط از فیدهای RSS عمومی انجام می‌شود؛ از منابعی استفاده کنید که حق بازنشر آن‌ها را دارید.
- برای ارتقا از نسخه قبلی، دوباره `install.php` را اجرا کنید؛ ستون‌های جدید به‌صورت خودکار اضافه می‌شوند و داده‌های موجود حفظ می‌شوند.
