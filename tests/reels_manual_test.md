# تست صفحه ریلز - راهنمای کامل

## خلاصه تغییرات انجام‌شده برای تست صفحه ریلز

### 🐛 باگ‌های رفع‌شده

1. **باگ سینتکس JS بحرانی - `{{}}` دوبل**
   - **قبل:** `var BKC={{csrf:...}}` → SyntaxError، تمام JS ریلز از کار می‌افتاد
   - **بعد:** `var BKC={csrf:...}` → صحیح
   - **فایل:** `index.php` خط 1096 سابق

2. **نشت تصویر محافظت‌شده**
   - **قبل:** `src="<?=h($imgs[0])?>"` مستقیم → تصویر قفل حتی بدون دسترسی قابل دیدن بود (فقط blur)
   - **بعد:** استفاده از `media_url()` با `thumb` برای قفل و `img` برای باز، تشخیص خودکار URL خارجی vs داخلی
   - **کد جدید:**
     ```php
     $reel_img_url = function(string $path, array $tip, ?array $user, bool $locked): string {
         if(preg_match('#^https?://#i',$path)) return $path; // خارجی
         return media_url($path, $locked?'thumb':'img', $tipId, $userId);
     };
     ```

3. **عدم به‌روزرسانی تصویر پس از باز کردن قفل**
   - **قبل:** بعد از `unlock` فقط `bk-blur` حذف می‌شد، تصویر همچنان thumb می‌ماند
   - **بعد:** سوییچ به `fulls[0]` از `data-fulls`

### ✨ بهبودهای UX برای تست بهتر

#### اینستاگرام-استایل
- **اسکرول تمام‌صفحه با snap:** `scroll-snap-type:y mandatory`
- **ستون عملیات کناری:** لایک (❤️/🤍 با شمارنده)، کامنت (💬)، اشتراک‌گذاری (➦)، باز کردن (💰/♥)
- **اطلاعات پایین:** آواتار، نام نویسنده، عنوان، توضیح، برچسب دسترسی/سختی/بازدید/امتیاز
- **دابل‌تپ لایک:** هم `dblclick` و هم تشخیص `click` سریع (300ms) برای موبایل
- **تعویض عکس:** کلیک روی تصویر → عکس بعدی، با `reel-dots` نقطه‌ای
- **پروگرس بار:** نوار سبز بالا که درصد اسکرول کل را نشان می‌دهد
- **کیبورد:** `ArrowDown` / `ArrowUp` برای جابجایی ریلز، `Escape` برای بستن کامنت
- **IntersectionObserver:** ریل فعلی را تشخیص و hash URL را به `#reel-{id}` به‌روز می‌کند

#### پنل نظرات
- **کشویی:** `bottom:-100%` → `bottom:0` با `transition .32s`
- **آجاکس:** `fetch('/ajax-comments?tip_id=')` برای دریافت، `POST action=comment` برای ثبت
- **به‌روزرسانی شمارنده:** پس از ثبت نظر، شمارنده کامنت +1 می‌شود

#### امنیت و محافظت
- `contextmenu` و `dragstart` فقط روی `reel-media img` جلوگیری می‌شود (نه کل صفحه)
- تصاویر با `user-select:none; -webkit-user-drag:none`

#### حالت خالی
- اگر هیچ قلقی نباشد، پیام زیبا با CTA به `/upload` و `/tips`

### 🧪 صفحه تست دمو (بدون نیاز به DB)

برای تست سریع فرانت‌اند بدون نیاز به دیتابیس MySQL:

- **Route:** `/reels-demo` یا `/reels-test`
- **فایل:** تعریف‌شده در `index.php` قبل از `reels` اصلی
- **داده:** ۵ قلق نمونه:
  - 1: رایگان، ۲ عکس
  - 2: با لایک، ۱ عکس
  - 3: پولی ۷۵k، ۳ عکس
  - 4: رایگان آسان
  - 5: با لایک + ویدیو یوتیوب
- **تصاویر:** `picsum.photos` (خارجی، بدون نیاز به uploads)
- **قابلیت‌ها:** تمام تعاملات به‌صورت دمو (بدون درخواست سرور واقعی) کار می‌کند

**چطور تست کنیم:**
```
/reels-demo
```
- اسکرول عمودی کنید (یا ArrowDown/Up)
- روی ❤️ بزنید → لایک
- دابل‌تپ روی تصویر → لایک با انیمیشن قلب
- کلیک روی تصویر (اگر چند عکس دارد) → عکس بعدی
- 💬 → پنل نظرات باز می‌شود
- ➦ → لینک کپی می‌شود
- باز کردن (برای قفل) → قفل باز می‌شود (دمو)
