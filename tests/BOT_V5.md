## ۲) موتور ربات — توابع جدید (index.php)

```php
bot_table_ready($table)      // کش‌شده؛ نصب‌های قدیمی بدون migrate هم کرش نمی‌کنند
bot_set_setting($key,$val)   // نوشتن مستقیم تنظیم بدون کش static
bot_get_setting($key)        // خواندن خام مستقیم از DB (برای قفل و offset)
bot_region_for_host($host)   // تشخیص منطقهٔ منبع (western/indian/chinese/japanese)
bot_title_tokens($title)     // توکن‌سازی عنوان با حذف کلمات عمومی فارسی/انگلیسی
bot_titles_similar($a,$b)    // شباهت جاکارد ≥ ۵۵٪ = تکرار
score_candidate($c)          // امتیاز ۰-۱۲۰: طول عنوان/متن، عکس، کلیدواژهٔ خرابی، اعتبار منبع
bot_update_source(...)       // ثبت سلامت منبع بعد از هر fetch (ok/fail + ms + تعداد آیتم)
bot_run_start / bot_run_end  // لاگ کامل اجرا در bot_runs
```

### جریان اجرای v5

```
۱. بررسی قفل (auto_collect_lock) — اجرای همزمان رد می‌شود (قفل قدیمی > ۱۰ دقیقه نادیده)
۲. شروع لاگ اجرا (trigger: manual | panel | cron + dry_run)
۳. چرخش منابع/کوئری‌ها با auto_collect_last_offset
۴. fetch منابع RSS با زمان‌سنجی + ثبت سلامت هر منبع در bot_sources
۵. کشف Reddit/Web با کوئری‌های چرخیده
۶. فیلترها (exclude / content_type / min_length) + امتیازدهی و مرتب‌سازی نزولی
۷. بارگیری ۸۰۰ عنوان اخیر ربات از DB برای تشخیص تکرار فازی
۸. حلقهٔ تولید قلق:
   - گارد زمان (time_limit) → پایان نرم
   - تشخیص تکرار ۳لایه → duplicates++
   - استخراج متن کامل + ترجمه + دسته‌بندی هوشمند + سختی/ابزار
   - دانلود تصاویر به /uploads/auto/{region}/ (+ شمارش)
   - dry_run؟ فقط گزارش — INSERT نمی‌زند
۹. پایان لاگ (created/scanned/duplicates/errors/images/sources/duration/regions)
۱۰. آزادسازی قفل
```

## ۳) جداول جدید دیتابیس

```sql
bot_runs    -- تاریخچهٔ اجراها: trigger, status, requested, created, scanned,
            -- duplicates, errors, images_downloaded, sources_ok/failed,
            -- duration_sec, dry_run, regions_json, message, created_at, finished_at

bot_sources -- سلامت منابع: url (unique), region, last_status, last_check,
            -- last_items, last_ms, ok_count, fail_count, consecutive_fails, last_error
```

ستون‌های جدید `settings`:

```
auto_collect_time_limit   INT DEFAULT 100     -- حداکثر ثانیهٔ هر اجرا
auto_collect_rotate       TINYINT(1) DEFAULT 1-- چرخش هوشمند منابع
auto_collect_last_offset  INT DEFAULT 0       -- نشانگر چرخش
auto_collect_lock         DATETIME NULL       -- قفل اجرای همزمان
```

> نصب تازه: `install.php` همه‌چیز را می‌سازد.
> نصب قدیمی: `php-extended/migrate.php?key=INSTALL_KEY` (قابل تکرار و امن).
> بدون migrate هم ربات کار می‌کند — فقط لاگ/پایش غیرفعال می‌شود (پیغام راهنما در پنل).

## ۴) پنل حرفه‌ای (`/admin?tab=collect`)

### ⚡ زیرتب «پیشخوان و اجرای زنده»
- ۸ کارت KPI: کل قلق‌های ربات، منتشرشده، در انتظار، هفت روز اخیر، نرخ موفقیت ۳۰ روز، میانگین هر اجرا، تکراری ردشده، امروز
- **اجرای زندهٔ AJAX** (`action=admin_bot_run`): تعداد/دسترسی/دسته + چک‌باکس 🧪 اجرای آزمایشی
  - نوار پیشرفت با مراحل (اتصال → فید → جستجو → امتیازدهی → ترجمه → دانلود عکس)
  - کارت‌های نتیجه: تولید / بررسی / تکراری / خطا / عکس / منابع ✓✗ / مدت / منطقه‌ها
  - به‌روزرسانی خودکار KPI از `ajax-bot-status` بدون رفرش
- نمودار ۱۴ روزهٔ قلق‌های ربات + وضعیت آخرین اجرا + وضعیت cron
- **جدول تاریخچهٔ ۱۵ اجرای اخیر** با نشانگر وضعیت سبز/قرمز/آبی

### 📡 زیرتب «سلامت منابع»
- کارت‌های خلاصه: پایش‌شده / سالم / خطای موقت / خراب (۳+ خطای متوالی)
- جدول هر منبع: منطقه، وضعیت، تعداد آیتم، زمان پاسخ (ms)، موفق/خطا، خطاهای متوالی، آخرین خطا

### 📦 زیرتب «محتوای ربات»
- لیست قلق‌های ربات با فیلتر وضعیت و صفحه‌بندی (۳۰تایی)
- عملیات سریع روی هر ردیف: ✅ انتشار / ⏸ برداشتن از انتشار / 🗑 حذف (`action=admin_bot_tip`)

### ⚙️ زیرتب «تنظیمات»
- همان ۱۷ تنظیم قبلی + ۲ تنظیم جدید (زمان اجرا، چرخش منابع) — سازگار با `action=admin_collect`
- کلید cron و دستور wget + دکمه‌های اجرای فوری (کلاسیک) و اجرای زنده

## ۷) چک‌لیست تست دستی (روی هاست)

1. `/install.php` نصب تازه یا `/php-extended/migrate.php?key=INSTALL_KEY` برای نصب قدیمی
2. `/admin?tab=collect` → زیرتب پیشخوان → 🧪 اجرای آزمایشی → باید گزارش «قابل تولید» بدهد و دیتابیس تغییر نکند
3. اجرای زندهٔ واقعی → نوار پیشرفت + کارت‌های نتیجه + KPI تازه

5. زیرتب سلامت منابع → وضعیت هر URL پس از اجرا ثبت شده باشد
6. زیرتب محتوای ربات → انتشار/توقف/حذف سریع کار کند
7. `/diag-version` → نسخهٔ `5.0`
8. تست ایستا: `node tests/full_test_runner.js` → ۱۲۱+ PASS

## ۸) v5.2 — رفع باگ‌های «گیرکردن اجرا» و «ثبت‌نشدن قلق»

### علت‌ها
1. **فاز کشف بدون سقف زمانی**: گارد زمان فقط در حلقهٔ آخر بود؛ جمع‌آوری منابع (۱۰ فید × retry + ۶ جستجو) روی هاست با اینترنت خروجی کند/بلاک چند دقیقه طول می‌کشید → PHP کشته می‌شد → لاگ «در جریان» می‌ماند و قفل ۱۰ دقیقه‌ای بسته بود → «اجراشده و متوقف نمی‌شود».
2. **شرط عکس اجباری**: قلق بدون عکس رد می‌شد → روی هاست با دانلود تصویر بلاک **هیچ قلگی** ثبت نمی‌شد.

### رفع‌ها
| مورد | توضیح |
| --- | --- |
| ددلاین سراسری | `$deadline = $startedAt + $timeLimit` در RSS، جستجو، retry، دانلود مقاله و حلقهٔ اصلی |
| ضدگیرکردن قفل | `register_shutdown_function` قفل را حتی هنگام کشته‌شدن پروسه آزاد می‌کند |
| پاک‌سازی یتیم | `bot_cleanup_stale_runs()`: running قدیمی‌تر از ۱۵ دقیقه → `stopped` |
| دکمهٔ توقف | `admin_bot_stop` + دکمهٔ «⏹ توقف ربات» در پنل؛ پرچم `auto_collect_stop` هر تکرار چک می‌شود |
| قلق بدون عکس | ذخیره ادامه می‌یابد؛ آیکون fallback در کارت‌ها |
| Circuit breaker | منبع با ۳+ خطای متوالی (۲۴س) در اجرای بعد skip می‌شود |
| هشدار هوشمند | اگر هیچ منبعی در دسترس نبود → «خروجی اینترنت هاست بسته است» + راهنما |
| سقف اجرا | `set_time_limit = time_limit + 60` برای پنل و cron |

### وضعیت‌های اجرا
`completed` · `failed` · `running` · `stopped` (توقف دستی / پروسهٔ قطع‌شده)

## ۹) v5.3 — رفع نمایش تصاویر، محتوای واقعی مطلب و لینک مطلب اصلی

### ۱) تصاویر نمایش داده نمی‌شدند
- **ریشه:** `media_url()` همهٔ عکس‌ها را از پروکسی `serve.php` می‌گذراند؛ serve فقط فایل محلی می‌خواند → وقتی دانلود روی هاست ناموفق بود و URL خارجی ذخیره می‌شد، پروکسی 404 می‌داد → هیچ عکسی نمایش داده نمی‌شد.
- **رفع:** URLهای `http(s)` مستقیم پاس داده می‌شوند (بدون پروکسی) + در ربات، وقتی دانلود ناموفق است همان URL اصلی در `images_json` ذخیره می‌شود (برای همهٔ نوع‌های دسترسی) و در گزارش اجرا «عکس با لینک مستقیم منبع» شمرده می‌شود.

### ۲) محتوای واقعی جایگزین قلق نمی‌شد
- **ریشه:** `build_steps_from_text` (گام‌ها از متن واقعی) هرگز صدا زده نمی‌شد؛ فقط ۵۰۰ کاراکتر ترجمه در blockquote و بقیه قلق از قالب‌های ثابت ساخته می‌شد.
- **رفع:** اگر متن ≥۳۲۰ کاراکتر باشد → گام‌ها از خود مقاله ساخته می‌شوند؛ توضیح کامل شامل «خلاصهٔ مطلب» ترجمه‌شده + «محتوای کامل استخراج‌شده از مطلب اصلی» (تا ~۸۰۰۰ کاراکتر، پاراگراف‌بندی‌شده) است؛ جملهٔ اول مطلب در خلاصهٔ کارت هم می‌آید.

### ۳) لینک مطلب اصلی
- تب «محتوای ربات»: ستون جدید «لینک مطلب اصلی» + ستون «عکس» (سبز=روی هاست، کهربایی=لینک مستقیم منبع)
- صفحهٔ قلق: کارت «🔗 مطلب اصلی (ربات)» فقط برای مدیران
